API 文档

这是一个轻量级账号管理服务的接口说明页。你也可以直接获取 OpenAPI： /openapi.json。

鉴权

注册/登录后返回 JWT Token，后续请求在 Header 里携带。

Authorization: Bearer <token>

常用接口

以下为最常见的工作流：导入 → 列表 → 发放 → 标记/删除。

Method Path 说明
POST /api/register 注册（可用 ALLOW_SELF_REGISTER=false 禁用）
POST /api/login 登录
GET /api/user 获取当前用户信息（需要 Token）
POST /api/admin/users 管理员创建用户（生产环境关闭自助注册时使用）
GET /api/admin/users 管理员用户列表（支持 page/per_page/q）
PUT /api/admin/users/<id>/password 管理员重置用户密码（会记录审计日志）
POST /api/account 导入账号（需要 Token）
GET /api/accounts 列表（支持 page/per_page/q/used）
GET /api/account 发放一个未使用账号（发放即自动标记为已用）
PUT /api/account/<id>/status 标记已用/未用
PUT /api/account/<id>/delete 软删除
GET /api/audit/logs 审计日志（需要 Token）

运维接口

用于监控与健康检查。

GET /api/health
GET /api/health?ready=1
GET /metrics

如设置 METRICS_TOKEN，/metrics 需要携带 Token（Bearer / Header / Query）。

合规说明（重要）

本项目不包含也不会执行任何第三方账号自动注册、验证码/风控绕过、批量注册等逻辑。 仅用于管理你已合法拥有的账号数据。
