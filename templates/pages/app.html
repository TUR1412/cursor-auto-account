账号管理控制台

本界面仅用于管理你已合法拥有的账号数据（导入 / 列表 / 发放 / 标记 / 删除）。 系统不会自动注册任何第三方账号，也不包含验证码/风控绕过逻辑。

登录 / 注册

获取 Token 后即可使用所有 API 与页面功能。

注册

账号操作

导入账号后，可一键“发放”一个未使用账号。

导入账号

{{ button("导入", id="btnImport", type="submit") }}
