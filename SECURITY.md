# Security Policy

## Supported Versions

Only the `master` branch is actively supported.

## Reporting a Vulnerability

Please do not open public issues for security reports.

Instead, contact the maintainers privately and include:

- A clear description of the issue and impact
- Steps to reproduce (proof-of-concept if possible)
- Affected version/commit
- Any suggested remediation

## Project Safety Notes

This project is intended for **account data you own legitimately**.
It does **not** include any third-party auto-registration, CAPTCHA bypass, or anti-bot circumvention logic.
